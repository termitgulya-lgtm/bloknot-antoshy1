# Блокнот Антоши

Этот Android-проект упаковывает исходный файл `www/index.html` в приложение Capacitor.

## Сборка в Codemagic
1. Загрузите содержимое этой папки в корень GitHub-репозитория.
2. В Codemagic выберите workflow `android-apk`.
3. Запустите сборку из ветки `main`.
4. Скачайте `app-debug.apk` из Artifacts.

Название: Блокнот Антоши
Application ID: com.antoshy.waiternotebook

Исходный HTML включён без переписывания и изменений.
